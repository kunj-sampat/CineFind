# CineFind 🎬

A clean, responsive web application to search for movies and curate a personal watchlist in real-time.

<img width="1917" height="1146" alt="image" src="https://github.com/user-attachments/assets/541d9cb9-e5c7-4dd7-b535-248fd1ac2859" />


## ✨ Features

- **Movie Search**: Instantly query movies with detailed overviews including release year, genre, IMDb rating, and director.
- **Personal Watchlist**: Add movies to your watchlist with a single click and manage them locally.
- **Minimalist UI**: Modern, distraction-free interface built with pure vanilla web technologies.

## 🛠️ Tech Stack

- **HTML5** – Semantic layout structure
- **CSS3** – Modern responsive styling
- **JavaScript (ES6+)** – DOM manipulation & async API handling
- **Movie API** – [OMDb API](https://www.omdbapi.com/) / [The Movie Database (TMDB)](https://www.themoviedb.org/)
